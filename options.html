ショートカット

  • Alt+X   分割画面を開く
  • Alt+C   左ペインを隠す / 復元
  • Alt+V   右ペインを隠す / 復元
  • Alt+M   モノクロ表示をトグル （全タブ対象）
  • 未割当   ブックマークバーの表示/非表示 — 推奨: Alt+S

入力欄にフォーカスがあっても発動します。キー変更は edge://extensions/shortcuts から可能です。
注: Edge / Chrome の制限でデフォルトショートカットは最大4個までのため、ブックマークバーの表示/非表示は手動で割り当てる必要があります。edge://extensions/shortcuts → Stealth Split Browser → 該当行の鉛筆アイコン → Alt+S を押して登録してください。
